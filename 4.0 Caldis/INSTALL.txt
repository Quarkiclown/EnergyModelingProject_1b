====================================================================
 CALDIS - INSTALLATION GUIDE
 Energy-system component modelling platform
====================================================================

This document explains how to install the Caldis library on your
computer. It takes about 5 minutes. Follow the steps in order.

You have received a file named:

    caldis-xxx.whl

("xxx" is the version number, e.g. caldis-0.4.0-py3-none-any.whl.)
This is the package to install. Do not rename it, do not unzip it:
pip takes care of that.


--------------------------------------------------------------------
 1. PREREQUISITE: PYTHON
--------------------------------------------------------------------

You need Python 3.9 or newer.

To check, open a terminal:
  - Windows : Start menu -> type "cmd" -> Command Prompt
  - macOS   : "Terminal" application
  - Linux   : your usual terminal

Then type:

    python --version

You should see something like "Python 3.11.5".

  -> If the command is not recognized, try "python3 --version".
     If that works, use "python3" and "pip3" instead of "python"
     and "pip" everywhere below.
  -> If Python is not installed, download it from
     https://www.python.org (tick "Add Python to PATH" on Windows).


--------------------------------------------------------------------
 2. GO TO THE FOLDER CONTAINING THE .whl FILE
--------------------------------------------------------------------

Find where the file caldis-xxx.whl is located
(for example, in your Downloads folder).

In the terminal, move into that folder with "cd":

  Windows (example):
    cd C:\Users\YourName\Downloads

  macOS / Linux (example):
    cd ~/Downloads

Check that the file is there:

  Windows :     dir
  macOS/Linux : ls

You should see "caldis-xxx.whl" in the list.


--------------------------------------------------------------------
 3. INSTALL CALDIS
--------------------------------------------------------------------

Still in the folder containing the .whl file, type (replace "xxx"
by the actual version in the file name):

    pip install caldis-xxx.whl

pip automatically downloads and installs the required dependencies
(numpy, scipy, CoolProp, pandas, matplotlib).
An internet connection is required for this step.

Wait for the message "Successfully installed caldis-xxx ...".


--------------------------------------------------------------------
 4. CHECK THAT IT WORKS
--------------------------------------------------------------------

Start Python:

    python

Then type these lines (one at a time):

    import caldis
    from caldis.core.system import System
    from caldis.solvers.solve import solve
    print("Caldis OK", caldis.__version__)

If "Caldis OK" is printed with no error, the installation
succeeded. Type "exit()" to leave Python.


--------------------------------------------------------------------
 5. USAGE
--------------------------------------------------------------------

You can now import Caldis components in your notebooks or scripts,
for example:

    from caldis.core.system import System
    from caldis.components import FluidBoundary, Compressor, Valve
    from caldis.components.HEX.heat_exchanger import SizingHX
    from caldis.solvers.solve import solve
    from caldis.solvers.dynamic import simulate
    from caldis.fluids import CoolPropBackend

The Caldis source code is freely readable: after installation it
lives in the "caldis/" subfolder of your environment (the
"site-packages" folder). You may read it to understand how the
components work. Do not modify it: write your own code in your
own notebooks.


--------------------------------------------------------------------
 6. SEE THE EXAMPLES
--------------------------------------------------------------------

The best way to learn how to use Caldis is to open the example
notebooks provided alongside this file, in the "examples/" folder:

    examples/00_source_valve_sink.ipynb   -- the build/solve/read loop
    examples/01_getting_started.ipynb     -- a compressor, with hints
    examples/02_heat_exchanger.ipynb      -- constraints and a heat exchanger
    examples/03_source_tank.ipynb         -- a dynamic (time) simulation

Open them with Jupyter (or VS Code) and run the cells top to bottom.
They show, step by step, how to build a system, impose conditions,
solve it, and read the results. Copy one and adapt it to your own
case.


--------------------------------------------------------------------
 TROUBLESHOOTING
--------------------------------------------------------------------

* "pip is not recognized":
    try   python -m pip install caldis-xxx.whl

* "python is not recognized":
    try "python3" / "pip3", or reinstall Python with
    "Add Python to PATH" ticked (Windows).

* "Could not find a version that satisfies ...":
    check your internet connection (dependencies are downloaded
    online).

* ModuleNotFoundError when importing:
    check that the install ended with
    "Successfully installed caldis-xxx ...", and that you started
    Python with the same interpreter you installed into.
